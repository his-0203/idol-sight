## 1. 가장 큰 구조적 결함 (3개 보고서 모두 합의)

현재 IDOL-SIGHT는 **K-pop 산업 분석 도구를 가상 아이돌에 그대로 적용**한 구조.
세 가지 핵심 사각지대가 동시에 존재한다.

### 1.1 같은 잣대로 8그룹 줄세우기 (인류학적 오류)

- **PLAVE**: K-pop 정통 — Corporate group, 그룹 채널 = 100%
- **ISEDOL**: 왁타버스 위성 — Segmentary lineage, 솔로:그룹 = 80:20
- **STELLIVE**: 일본 V-tuber — Confederation, 멤버 portfolio가 1차

서로 다른 사회적 실체를 같은 Health Score로 줄 세우면, 정의상 PLAVE의 dominant signal로만 측정해서 PLAVE가 영원히 1위로 나오는 자기충족 예언이 된다.

### 1.2 ref 값 부정렬로 변별력 손실 (정량 오류)

- `subscribers REF=1M` → PLAVE만 1.0 saturate, 나머지 0.05~0.3
- `views REF=200M`, `quality REF=10M(top10 평균)` 동일 패턴
- Market Share의 "yt_views + dc_posts + naver*100" 단위 불일치 → **YouTube 누적뷰가 99% 가중**. PLAVE 51% 점유율은 산식 인공물이지 실제 시장 점유가 아님.

### 1.3 의례·친밀성 경제 미측정 (질적 오류)

팬덤이 자기 화력을 측정하는 핵심 시그널 20개 중 **3~4개만** BI에 잡힘.
빠진 critical 시그널: 음방 1위, 콘서트 매진 속도, 멤버십 가입자, **개인방송 동시 시청자** (V-tuber 핵심), 슈퍼챗, 합방 빈도, 음원 dive curve.

## 4. 3개월 (~8월 초): 4-Factor Health + 그룹 모델 분류

### 4.1 Health Score 4-factor 재설계

```
Health = w1·Reach + w2·RitualVictory + w3·Mobilization + w4·Intimacy
```

- **Reach**: 구독자, 조회수, 뉴스 (현 지표 대부분)
- **RitualVictory** (의례 승리): 음방 1위, 차트 진입, 외부 콜라보
- **Mobilization** (동원): 초동, 콘서트 매진 속도, 팬싸 응모, 멤버십
- **Intimacy** (친밀성): 동시 시청자, 슈퍼챗, 합방 빈도, 2차 창작

가중치는 그룹 모델별로 분리:
- PLAVE 계열 (Corporate): Ritual + Mobilization 비중 ↑
- ISEDOL 계열 (Segmentary): Mobilization + Intimacy
- STELLIVE 계열 (Confederation): Intimacy 압도적

### 4.2 Group + Member dual entity 모델

새 테이블 `agg_group_combined(group_key, snapshot_at, combined_method, ...)`.
combined_method 컬럼으로 3가지 view 동시 저장:
- `group_only`: 그룹 채널만 (현재 default)
- `sum`: 그룹 + 멤버 단순합
- `weighted`: 그룹×1.0 + 멤버×0.7 (collab dedup)

UI에서 토글 — PLAVE는 group_only, STELLIVE는 sum이 default view.

### 4.3 추가 P0 KPI

- **24h Velocity** (신규 영상 첫 24h 조회수 / 채널 평균) — 컴백 임팩트 표준
- **음원 dive curve** (1d/3d/7d/14d/30d 곡선 + 패턴 분류)
- **콘서트 매진 시간(초)** — 인터파크/예스24 티켓 오픈 시각 트래킹
- **합방 빈도 + 네트워크** — V-tuber 그룹 cohesion 측정

## 7. 윤리 가이드라인 (Anthropologist §E)

1. **본체 정보를 BI에 직접 저장 금지** — 위기 감지 키워드 알림은 OK, 신상은 X.
2. **2차 창작 트래킹은 "양"만, "내용"은 저장 금지** — 호혜 경제는 비공식성에 의존.
3. **디시 게시물 원문 저장 신중하게** — 익명성 침해 가능. 집계 결과만.
4. **MiiWAN 등 자사 그룹 위주로 깊이, 경쟁사는 외형만** — 윤리 경계 + 법적 risk.
5. **위기 알림은 인간 검증 필수** — false positive 시 회사 측 과잉 반응이 사건을 키울 수 있음 (Streisand effect).
