# 시장 지도 산식 v2 (설계)

2026-08-04 · 배경: 활동 없는 MYRAKL이 지도에서 자사·B:DAWN보다 우위로 표시.
데이터 원인(네이버 오탐 116건)은 0112 + reeval로 정화 완료. 이 스펙은 남은
**구조 원인** — ① 소형 그룹 신호 0-클램프 ② 뉴스 누적 스톡의 영구 관성
③ y축 median의 업로드 볼륨 역상관 — 을 고치는 v2 개편이다.

**검토 절차**: 지표 설계·제품(의사결정 소비자)·구현 실무 3관점 서브에이전트
패널 병렬 검토 후 종합. 주요 합의: 라벨-정의 정합성 버그로 프레이밍(자사
유리 조정 아님), 전 그룹 대칭 적용 명문화, 순위 diff 리포트를 배포 게이트로,
8월 투자사 보고 **전에** 1회로 완결(부분 변경 반복 금지).

## 결정 사항 (패널 종합)

### ① 정규화 밴드 하한 1% → 0.1% (awareness `_normalize_log`)
- 리더 대비 [1%,100%] 밴드가 구독 12K·조회 8.6M 미만을 전부 0으로 클램프 —
  소형 그룹끼리는 뉴스(가중 0.15)만 남아 노이즈가 좌표를 지배하는 증폭 요인.
- [0.1%,100%] 3데케이드로 완화. 단조 변환이라 **신호 내 순위 불변**, 점수
  크기만 재분포. 구현: 상수 1줄 + 테스트.

### ② 뉴스 신호 = 최근 90일 기사 수 (누적 → 플로우)
- **새 컬럼 `agg_summary.naver_news_90d`** (migration 0113). `naver_total_news`
  는 **불변** — health_score가 5개 지점에서 소비하므로 절대 건드리지 않는다
  (구현 실무 패널 1순위 리스크).
- agg_summary 빌드에 windowed COUNT 추가: `published_at >= now-90d AND
  COALESCE(is_excluded,0)=0`. NULL published_at은 창 밖(=제외) — controversy
  창과 동일 관용구. relevant 기사 published_at 결측 0.27%라 가용성 검증됨.
- awareness는 news 입력을 `naver_news_90d`로 교체. 컬럼 미존재 D1(마이그레이션
  미적용)에서는 `naver_total_news` 폴백(기존 `_has_adj_columns` 감지 패턴).
- 하드 창 채택(감쇠 기각): 설명 가능성("최근 90일 기사 수" 한 줄) + 구현
  단순성 + log1p가 클리프 완만화. 제품 패널의 "하드컷=조작 인상" 우려는
  ⓐ 전 그룹 대칭 적용 명문화 ⓑ 창 60/90/120일 순위 강건성 확인·명기로 상쇄.

### ③ y축 = 반응 상위 5편 median (볼륨 역상관 제거)
- `est_active_core` = 표본(56일 창, <3편 시 최신 12편 폴백 — semantics 불변)
  중 **댓글수 상위 5편**의 median 댓글. `est_engaged_fans` = **좋아요 상위
  5편**의 median 좋아요(같은 편향 보유라 일관 적용).
- 핵심 성질: 영상 추가가 상위 5 median을 낮출 수 없음(약단조) — "많이
  올릴수록 불리" 구조 소멸. 쇼츠·일상 클립은 상위 5에 못 들면 자동 배제.
- 표본 <5편이면 있는 만큼(현행 median과 연속). K=5 자의성은 K∈{3,5,7} 순위
  안정성 확인으로 방어(제품 패널 우려 대응).
- 공유 함수 `estimate_video_engagement`(live_activity와 공유)는 **불변** —
  표본 선택만 바꿔 두 번 호출. like_rate/comment_rate/video_count는 전체
  표본 기준 유지(축 아님). adj 경로는 suspect 제외 **후** 동일 top-5.
- 파생 효과: MiiWAN 심층(FanActivityCard, agg_live_activity_summary)과 숫자가
  달라짐 — 버그 아님, 두 화면 카피에 기준 명시로 해소(구현 실무 패널 2순위
  리스크 대응).

### ④ 프런트 카피
- MarketOverview: 인지도·추정 코어/관여팬 툴팁에 v2 정의("최근 90일 기사"
  / "반응 상위 5편 median"), 지도 아래 각주 1줄: "산식 v2(2026-08) — 전
  그룹 동일 적용".
- MiiWANPosition: 팬덤 프로필 힌트 동기화.

### ⑤ 배포 게이트 (머지 전 필수)
- prod D1 실데이터로 v1/v2 좌표·순위 diff 리포트 생성(K-POP 카테고리):
  MYRAKL 역전 해소 확인 + 창 60/90/120·K 3/5/7 강건성 → PR 본문에 첨부.
- 시계열 단절: 재백필 안 함(프런트는 최신 스냅샷만 소비, 90일 창 앞부분이
  수집 개시 이전이라 재백필이 오히려 편향). 단절 시점은 이 스펙과 PR로
  문서화(formula_version 컬럼은 과잉으로 기각).
