# 월간 보고서 자동 생성·다운로드 (설계)

2026-08-04 · 3관점 패널(보고서 구성 PM · 지표/차트 설계 · 구현 실무) 병렬 검토 종합.
요구: 매월 초 브리핑·포지션·시장분석 내용 기반 월간 덱 자동 생성 → 개요 페이지
다운로드 버튼(준비 시 활성화) + 알림.

## 아키텍처 (구현 실무 패널 권고 ⓐ)

```
매월 1일 00:23 UTC cron (+ workflow_dispatch --month 재생성)
  → python -m idol_sight monthly-report [--month 2026-07] [--investor-final]
      analysis/monthly_report.py  D1 조회·월간 집계·자동 결론(순수 함수)
      analysis/monthly_render.py  자립 HTML 덱 렌더(인라인 SVG·인쇄 안전 CSS)
      → D1 monthly_reports(0117, (month, edition) PK, DELETE+INSERT 멱등,
        800KB fail-fast 가드) → notify_alert(info) Discord
프런트: GET /api/monthly-report?list=1 → 버튼 상태 /
        ?month&edition=internal|investor → text/html attachment (HMAC 미들웨어 자동)
버튼: MiiWANBriefing 히어로 헤더(3탭 공통 영역)
```

- 요청 시 동적 생성 기각 — 이 리포는 소급 정정이 일상이라 보고서는 **생성 시점
  스냅샷으로 동결**("N일 생성 · 데이터 기준" 스탬프), 재생성은 dispatch 경로.
- 저장은 D1 TEXT로 충분(예상 150~400KB, REST 바디 실질 상한 ~800KB, base64 이미지
  금지 명문화). R2 도입 근거 없음.

## 덱 구성 (PM 패널: 코어 11장 + 내부 부록 2장, 단일 파이프라인 2판)

내부판 = 13장 / 투자사판 = 코어 11장(게이트 적용, DRAFT 워터마크 기본 —
`--investor-final` 로만 해제). 장 구성·핵심 질문·제외 목록·게이트 G1~G8은 PM
패널 표 그대로(주요: 위기 모니터·LLM 원문 = 부록 격리, 경쟁사 유료 의심 표현 ·
곡 코드네임·제작 이슈 = 전판 금지, 투자사판 KPI 장은 밴드 축 숨기고 판정 색만).
장 결론은 전부 템플릿 자동 문장(LLM 신규 호출 0 — 부록 A2만 저장된 insights
큐레이션 인용).

## 지표·차트·판정 (지표 설계 패널 카탈로그 준수)

- 월간 단위: 스톡=UTC 월말 스냅샷(위버스만 KST day) / 플로우=월말 델타(일별 합산
  금지) / avg_ccv=방송별 평균의 월평균(기존 정의 불변) / 주간 지표=월내 마지막
  final 주 / MoM 표기 `28.6k (전월 27.9k)` / 판정은 확정월만.
- 시계열은 `data_source='live'`만, NULL→0 변환 금지, 그룹 간 뉴스 비교 금지,
  56일 창 지표는 "최근 56일" 라벨 참고 타일로만.
- 자동 결론 R1~R7(KPI 종합/개별·티어 이동·코호트 순위·사분면 이동·스파이크
  각주·데이터 신뢰 각주) — 전부 결정적 템플릿.
- 색: MiiWAN #75d7d1 · 비교군 중립 회색 · 밴드 음영 12% · 미달 주황 1색.
  인쇄 안전 3종(print-color-adjust exact + -webkit- 병기, mm 재정의 금지,
  밝은 배경) 템플릿 고정. 소형 텍스트에 밝은 키컬러 금지.
