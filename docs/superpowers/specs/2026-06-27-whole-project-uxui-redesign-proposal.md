# idol-sight 전체 UX/UI 재설계 제안서

> **기준일**: 2026-06-27 · **성격**: 프로젝트 전반(IA·네비·뷰·비주얼 시스템) 재설계 제안. 코드 착수 전 방향 확정용. 리서치 근거: 현재 구조 4종 감사(네비IA·뷰 인벤토리·비주얼 시스템·MarketOverview) + 내부 B2B 분석도구 UX 10원칙(NN/g·IBM Carbon·AWS Cloudscape·Amplitude·Shneiderman·Stephen Few 등 출처).

## 0. 한 줄 결론

**idol-sight는 사실상 두 제품이 평평한 11탭 네비에 끼어 있다** — (A) 3사가 시장을 *모니터링*하는 제품, (B) 자사(MiiWAN) 실데이터로 *심층 분석*하는 제품. 지금 네비는 이 구분을 숨기고, 같은 숫자를 여러 뷰에 중복시키며, 비주얼 토큰을 정의해두고 안 지킨다. 재설계의 축: **좌측 사이드바 IA(의도별 그룹) + 그룹 master-detail + MiiWAN 특권 영역 + presentation/exploration 분리 + 중복 통합 + 디자인 토큰 강제**.

## 1. 사용자·맥락 (확정)

- **누가**: 파트너 3사. **목적**: 사내 의사결정 + 모니터링. 분석가가 아닌 **비즈니스 의사결정자**.
- **두 모드**: (A) 타 그룹 = 모니터링/비교. (B) MiiWAN = 자사 실데이터(라이브 채팅 sentiment·YT Analytics OAuth 국가별·찐팬·시장확장·굿즈) **심층 시장분석** → 별도 페이지인 이유.
- 카테고리(K-POP/서브컬처)는 비교 불가 → **구조적 분리**(필터 아님).

## 2. 진단 — 왜 누적돼 보이나 (감사 근거)

**2.1 네비 IA**
- GNB는 5탭(시장개요·주간·인사이트·숏폼·MiiWAN) + ⚙상태의 **평평한 목록**. 의도별 그룹·구분선 없음.
- 그룹 상세(content/members/community/risk)는 GNB에 없고 카드/검색으로만 진입. **그룹 모드 안에서 다른 그룹·다른 하위탭으로 이동할 수단이 없음**(헤더 "그룹 모드"는 텍스트, 클릭 불가). `growth`는 **고아 라우트**(어떤 UI로도 도달 불가).
- 인증은 **단일 공유 비밀번호**(3사 구분·역할 없음).

**2.2 뷰 중복 (누적의 핵심)**
- 인사이트 카드가 **4곳**(Insights·WeeklyUpdate·MiiWANBriefing·GroupContent) 동일 컴포넌트로 렌더. 같은 행이 동시에 4곳 노출 가능.
- 알림이 **2곳**(GroupContent의 GroupAlertSection ≡ PRRisk) 거의 복제. 논란 신호는 **3단계**(Community 원문 → PRRisk 집계+스파이크 → GroupContent 파생칩).
- WeeklyUpdate 인사이트 ⊂ Insights. 전역 ShortsTrend가 **MiiWAN 전용 패널로 시작**(스코프 누수).
- GroupContent가 과적재 — PRRisk·Insights·Community 몫까지 흡수해 나머지 per-group 탭의 한계 정보가치를 깎음.
- MarketOverview 자체: 인지도·코어·organicity가 카드와 사분면에 **2~3번** 중복(이전 감사).

**2.3 비주얼 시스템**
- 토큰은 있으나(brand·grade·group·surface·font scale·radii) **안 지킴**: `.card` 정의돼도 뷰에서 3곳만 사용, 50+곳이 수동 `rounded-lg border ...`를 4가지 투명도(/30·/40·/50·/60)로 재작성. `text-label`·`text-body` 정의 후 **미사용**. `styles.css`에 ~430줄 plain-CSS 섬(DebutWindow·COB)이 raw hex로 토큰 우회.
- **브랜드 키컬러 #06C755(사내)·#ABE3E4(3사)가 코드에 전혀 없음**(brand는 violet #8b5cf6). 등급 B 색이 canonical(cyan) vs GroupContent(violet=로고색) **충돌**. `text-zinc-600`(—, 보조보조 텍스트)은 다크 배경 대비 **AA 미달**.

## 3. 제안 — 새 정보구조 (IA)

연구 권고(IBM Carbon presentation/exploration · Cloudscape 글로벌/구조 네비 분리 · Datadog/GA4 master-detail · Amplitude 의도별 그룹화 · 멀티테넌트 자사 우선)를 idol-sight에 적용:

```
┌──────────────────────────────────────────────────────────┐
│ TOP BAR   idol-sight        [관점: MiiWAN/3사 ▾]  🔍  ⚙  ? │
└──────────────────────────────────────────────────────────┘
LEFT SIDEBAR (의도별 그룹, 2단계 max)
──────────────────────────────────────────
 ◉ 시장 펄스        ← presentation(한눈에)
    시장 개요         (12그룹 비교·랭킹·KPI strip)
    주간 브리프       (so-what 서술 + 이상치)
    인사이트          ← 단일 정규 피드(타입·스코프 필터)
    숏폼 트렌드
──────────────────────────────────────────
 ◉ K-POP (Corporate)  ← exploration(master-detail)
    그룹 비교 (리스트)  → 그룹 선택 시 엔티티 셸:
       [개요|멤버|커뮤니티|PR·리스크|성장]   ← 하위탭(상단탭 아님)
──────────────────────────────────────────
 ◉ 서브컬처 / V-튜버   ← 동일 master-detail
    그룹 비교 → 엔티티 셸 하위탭
──────────────────────────────────────────
 ★ MiiWAN (자사)       ← 특권 심층분석 존(#06C755 액센트)
    개요 · 라이브챗 인사이트 · 시장확장(국가) · 굿즈 · PR레이더
──────────────────────────────────────────
 �◦ 시스템 상태(하단, 접힘)
```

**핵심 결정**
1. **11 평평탭 → 5 의도그룹**. per-group 5뷰는 **그룹 엔티티 셸의 하위탭**으로 접어 top-level에서 4~5개 제거(정보 손실 0, 관계 명시). 그룹 셸 안에서 **그룹 전환 셀렉터 + 하위탭 바** 제공(현재 막다른 그룹모드 해소). `growth` 고아 해소.
2. **카테고리 = 사이드바 구조 분리**(필터 아님). 파트너가 자기 도메인을 한눈에.
3. **MiiWAN = 특권 존**(별·"자사" 배지·#06C755 액센트), 항상 펼침. 시장 비교 뷰에선 MiiWAN을 **하이라이트 링/"자사" 라벨**로 항상 식별.
4. **TOP BAR = 글로벌 컨텍스트**(관점 스위처·검색·설정), 구조 네비는 사이드바(Cloudscape 원칙).
5. **presentation vs exploration**을 시각적으로 구분(시장펄스=읽기/저상호작용, 그룹·MiiWAN=필터·드릴다운).

## 4. 제안 — 중복 통합

- **인사이트 단일화**: 정규 피드 1곳 + 스코프/그룹 필터. WeeklyUpdate·GroupContent·MiiWAN은 *필터된 뷰*로 재사용(복제 아님). WeeklyUpdate의 고유값(Hanteo·movers)만 남김.
- **알림 단일 렌더**: GroupContent와 PRRisk가 같은 alert 컴포넌트를 공유(엔티티 셸 PR·리스크 탭이 정규 홈, 개요는 요약+링크).
- **논란 신호 1체인**: 원문(커뮤니티)→집계(리스크)→칩(개요)을 같은 데이터의 *드릴다운 단계*로 명시(중복 아닌 계층).
- **스코프 정합**: 전역 ShortsTrend의 MiiWAN 전용 패널은 MiiWAN 존으로 이동.

## 5. 제안 — 비주얼 시스템 정비 + 브랜드 키컬러

- **토큰 강제**: `.card`·font scale(`text-label`/`text-body` 도입)·radii를 전 뷰에 적용, 수동 surface 4종 투명도 통일, plain-CSS 섬을 토큰화. 등급 B 색 충돌 해소(canonical 단일화). `text-zinc-600` 대비 AA 통과 값으로 상향.
- **브랜드 키컬러를 IA 의미에 매핑**: **#06C755(사내) = 자사/MiiWAN 정체성 액센트**(특권 존·"자사" 하이라이트), **#ABE3E4(3사) = 시장/파트너 공유 컨텍스트 액센트**. 즉 브랜드 색이 제품의 핵심 구분(자사 vs 시장)을 강화.
  - ⚠ 주의: #06C755은 status-green(긍정)과 가까움 → **데이터 시각화의 긍정색으로는 쓰지 말고**, 네비·정체성 영역(자사 존·로고·"자사" 링)에만 한정해 status와 충돌 회피.
- **색 문법 분리 재확인**(IBM Carbon): status(적/황/녹) / 등급(diverging) / 카테고리(2색=K-POP·서브컬처) / 경고(organicity=amber). 그룹별 개별색 남발 대신 위치·라벨로 식별.

## 6. 단계 로드맵 (빅뱅 금지)

각 단계가 독립 배포 가능하고 위험이 낮은 순:

- **P0 — 비주얼 토큰 기반**(IA 불변, 위험 최저, 일관성 즉효): 토큰 강제·plain-CSS 섬 정리·등급B 충돌·대비 수정·브랜드 키컬러 도입. "의도된 디자인"으로 보이게.
- **P1 — 네비 IA 재구조**(최대 구조 효과): 사이드바·의도그룹·그룹 엔티티 셸(하위탭·그룹 전환)·MiiWAN 특권 존·TOP BAR 컨텍스트. growth 고아 해소.
- **P2 — 중복 통합**: 인사이트 단일 피드·알림 단일 렌더·논란 계층 명시·스코프 정합.
- **P3 — MarketOverview 재설계**: overview KPI strip → 정렬 비교표(넓이×깊이=태그 컬럼, 셀내 서열 해소) → 포지셔닝 맵 접힘 → SoV/곡선 → MiiWAN 하이라이트. (이전 리서치 결론 반영)
- **P4 — 의사결정 지원 reframe**: 주간/인사이트를 "so-what" 브리프로(이상치 헤드라인+추세화살표+한 줄 해석), MiiWAN 우선 노출.

**권장 착수**: P0(기반) + P1(IA)부터. 가장 큰 체감 변화이고 이후 단계의 토대.

## 7. 비범위 / 주의

점수 산식·수집은 불변(UI/IA 한정). 인증 역할분리(3사 계정/권한)는 백엔드 변경이라 별도 검토(현재 단일 비밀번호). 빅뱅 리라이트 금지 — 단계별 배포·검증.
